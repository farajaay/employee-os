# Baseline

## `index.upstream.html` — the pristine source artifact (M-00)

The product exactly as it was served, before the rename. **Do not edit this file.**

It is here because the repository named as the programme's source of truth,
`farajaay/fatimah-work-os`, is **empty** — zero commits, zero branches. There was no
upstream to import from and none to diff against. The live deployment at
`https://fatimah-work-os.vercel.app/` was used as the source instead: 30,904 bytes,
fetched 26 August 2026. Vercel serves the file statically with no build step, so this
is the deployed artifact byte for byte.

This copy is what makes M-00's *Done when* checkable at all. To verify that the product
name is the only change in the root `index.html`:

```bash
diff <(sed 's/Employee OS/Fatimah Work OS/g' index.html) docs/baseline/index.upstream.html
```

Silence means the name is the only difference. That check passed at M-00 and should be
re-run before M-04 and M-05 are declared done.
